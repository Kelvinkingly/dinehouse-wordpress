# DineHouse — Restaurant Digital Experience

[![DineHouse homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/dinehouse-homepage.jpg)](https://dinehouse-knowedge.infinityfreeapp.com/)

[Visit live website](https://dinehouse-knowedge.infinityfreeapp.com/)

Independent WordPress portfolio platform by KnowEdge Business Development Services Ltd. Editable menu records, category and dietary filters, browser-local cart with quantity and pricing, table planning, responsive layouts, custom favicon and FAQs.

Illustrative menu and images only. No real food orders, payments, bookings or personal information are accepted or transmitted.

## Installation

Zip `theme/dinehouse` including the top-level directory. Upload through WordPress Appearance → Themes and activate. Initial menu dishes are seeded once.
